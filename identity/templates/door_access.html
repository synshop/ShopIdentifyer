This page tracks RFID tokens in this system. It doesn't change the door controller, so add or remove cards there by hand as well.
  • Unassigned: tokens not attached to a member. Use Add New Token to register a new card, then Assign to give it to a vetted, active member.
  • Assigned: members' tokens that are on the door controller (they have an EB ID).
  • Inactive: members' tokens that have been taken off the door controller (no EB ID), usually because the member was offboarded. Rows in yellow are marked Active but have no EB ID, so check the controller.
